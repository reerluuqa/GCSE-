01 / Linear simultaneous equations

Cancel one variable. Find the other.

A solution must satisfy both equations. Use elimination when coefficients can be matched; substitution when a variable is already isolated.

  1. Multiply one or both whole equations to match a coefficient.
  2. Same signs: subtract. Opposite signs: add.
  3. Solve, substitute back and check both equations.
2x + y = 8   and   x − y = 1
Add: 3x = 9 → x = 3, y = 2
Pitfall: when subtracting, use brackets around the entire second equation so every sign changes.
When is substitution easier?

For y = 3x − 2 and 2x + y = 13, replace y with all of 3x − 2: 2x + (3x − 2) = 13. This gives x = 3 and y = 7.

02 / Quadratic equations

Make it equal to zero.

A quadratic contains an x² term. In a monic quadratic its coefficient is 1. Rearrange first, then look for factors.

x² + bx + c = (x + p)(x + q)
p + q = b   and   pq = c

When a product is zero, at least one factor is zero. Solve each linear factor to get all roots.

x² − x − 6 = 0
(x − 3)(x + 2) = 0 → x = 3 or −2
Pitfall: never divide by x unless you have accounted for x = 0. From x² = 4x, use x(x − 4) = 0.
Special patterns worth spotting

Difference of squares: x² − 25 = (x − 5)(x + 5). Repeated root: x² + 6x + 9 = (x + 3)². Common factor: 3x² − 12x = 3x(x − 4).

03 / Non-monic quadratics

Use the product ac.

For ax² + bx + c with a ≠ 1, find two numbers whose product is ac and whose sum is b. Split the middle term, then group.

6x² + 11x + 3
= 6x² + 9x + 2x + 3
= 3x(2x + 3) + 1(2x + 3)
= (3x + 1)(2x + 3)

For the equation equal to zero, the roots are −1/3 and −3/2. If you cannot find rational factors, use the formula.

Pitfall: the two split numbers are not the roots. Solve the factors, including their coefficients.
A fast check

Multiply the first terms, then the last terms, then check the two cross-products sum to bx. Take out a common numerical factor first if possible.

04 / Formula & completing the square

Two methods that always work.

First write ax² + bx + c = 0, where a ≠ 0. Keep the signs of a, b and c.

x = (−b ± √(b² − 4ac)) / (2a)

The whole numerator is divided by 2a. Evaluate both the plus and minus versions. Round only at the end; for exact answers, retain surds.

x² + 8x + 5 = (x + 4)² − 11
2x² + 8x + 5 = 2(x + 2)² − 3

To complete the square, halve the x coefficient after factoring out a, then balance the added constant.

Root reasoning: D = b² − 4ac. D > 0: two distinct real roots. D = 0: one repeated real root. D < 0: no real roots. Use this as a shortcut for stretch problems; completing the square also shows the number of solutions.
Exact surd example

x² − 6x + 2 = 0 → (x − 3)² = 7 → x = 3 ± √7. The two signs are essential.

05 / Quadratic simultaneous equations

Substitute. Solve. Pair the answers.

For a line and a quadratic curve, replace one variable using the linear equation. The resulting quadratic may have two, one or no real solutions.

y = x + 2   and   y = x²
x² = x + 2 → (x − 2)(x + 1) = 0
(x, y) = (2, 4) or (−1, 1)

For a circle, substitute with brackets: if y = 2x + 1, then y² = (2x + 1)² = 4x² + 4x + 1.

Pitfall: two x-values are only half the job. Find each corresponding y and write two complete coordinate pairs.
Why does a repeated root mean touching?

Solving simultaneously finds intersection points. A repeated root gives a single x-value where the line meets the parabola; the line is tangent there. Set the completed square equal to zero or use D = 0.

06 / Quadratic graphs

Let the form reveal the feature.

  • y = ax² + bx + c: y-intercept (0, c).
  • y = a(x − r)(x − s): roots r and s.
  • y = a(x − h)² + k: turning point (h, k), symmetry line x = h.
  • a > 0 opens upwards (minimum); a < 0 opens downwards (maximum).

Sketch a smooth symmetric curve through labelled intercepts and the turning point. To solve f(x) = k graphically, read intersections with y = k.

Graph transformations: f(x) + k moves the graph up k. f(x − h) moves it right h. −f(x) reflects it in the x-axis. For positive a, f(x) > 0 lies outside two distinct roots; f(x) < 0 lies between them.
Find a curve from its roots

Roots r and s give y = a(x − r)(x − s). Substitute another point to find a. Do not assume it equals 1.

The habits that protect your marks

Show the method. Write the rearranged equation, factorisation or formula substitution, and each final solution. A correct final answer check cannot judge the quality of your working.

Check the context. Lengths must be valid, denominators cannot be zero, and a question asking for coordinates needs both x and y.

Choose exact or approximate. A surd answer and a rounded decimal serve different instructions. For numerical questions, follow the specified accuracy.

Use mistakes. Read the solution, identify the first incorrect line in your working, then retry later without looking.
